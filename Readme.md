# CI e Testes Inteligentes com Cypress 🤖

[![CI Pipeline](https://github.com/mauriciorimes/ci_testes_inteligentes_mauricio/actions/workflows/ci.yml/badge.svg)](https://github.com/mauriciorimes/ci_testes_inteligentes_mauricio/actions/workflows/ci.yml)

Repositório criado para a disciplina Engenharia de software da pós graduação em desenvolvimento web e mobile, demonstrando a configuração de testes automatizados com e sem IA utilizando Cypress e GitHub Actions.

## 🛠️ Como executar localmente

1. Clone o repositório.
2. Instale as dependências com `npm install`.
3. Para abrir a interface interativa do Cypress: `npx cypress open`.
4. Para rodar os testes em modo invisível (headless): `npx cypress run`.
